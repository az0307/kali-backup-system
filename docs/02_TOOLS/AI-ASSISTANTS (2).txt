### Quick Download Script
```bash
#!/bin/bash
# download-hf-models.sh

MODELS_DIR="/media/kali/KaliShare/models"
mkdir -p "$MODELS_DIR"

echo "Downloading models (requires internet)..."

# Pentester model (~4GB)
huggingface-cli download TheBloke/CodeLlama-7B-Instruct-GGUF \
  --local-dir "$MODELS_DIR/codellama-7b" \
  --ignore-files *.md *.txt 2>/dev/null || echo "Manual: https://huggingface.co/TheBloke/CodeLlama-7B-Instruct-GGUF"

echo "Models saved to: $MODELS_DIR"
echo "Use: ollama create --path \$MODELS_DIR/model.gguf"
```

## Custom AI Widgets

### Python Chatbot
```python
#!/usr/bin/env python3
# Simple chatbot with local model

import requests

def chat(prompt, model="llama2"):
    r = requests.post(
        "http://localhost:11434/api/generate",
        json={"model": model, "prompt": prompt}
    )
    return r.json()["response"]

while True:
    print("🤖:", chat(input("You: ")))
```

## Model Comparison for Pentesting

| Model | Size | Best For | URL |
|-------|------|----------|-----|
| **CodeLlama 7B** | 4GB | Code, scripts | TheBloke/CodeLlama-7B-Instruct-GGUF |
| **Mistral 7B** | 4GB | General sec | TheBloke/Mistral-7B-Instruct-v0.2-GGUF |
| **DeepSeek Coder** | 4GB | Code analysis | TheBloke/deepseek-coder-6.7B-instruct-GGUF |
| **Phi-2** | 2GB | Light, fast | TheBloke/Phi-2-GGUF |

### Best for Pentesters
1. **CodeLlama** - Write scripts, analyze code
2. **DeepSeek Coder** - Code review, vulnerability finding
3. **Mistral** - General conversation, explanations
