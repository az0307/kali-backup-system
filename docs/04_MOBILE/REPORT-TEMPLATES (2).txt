# Report Templates & Documentation

## Pentest Report Structure

### 1. Executive Summary
```
# Pentest Report - [Client Name]
## Date: [DATE]
## Scope: [SCOPE]

## Overview
[Brief description of assessment]

## Risk Summary
| Severity | Count |
|----------|-------|
| Critical | X |
| High | X |
| Medium | X |
| Low | X |
| Info | X |

## Key Findings
[Top 3-5 issues]

## Recommendations
[Priority recommendations]
```

### 2. Technical Findings
```
## Finding: [Title]
### Severity: [Critical/High/Medium/Low/Info]
### Description:
[What is the issue]

### Impact:
[Security impact]

### Proof of Concept:
```bash
# Steps to reproduce
```

### Remediation:
[How to fix]

### References:
- CVE-XXXX-XXXX
- OWASP
```

### 3. Methodology
```
## Phase 1: Information Gathering
- Passive reconnaissance
- Active reconnaissance

## Phase 2: Vulnerability Assessment
- Port scanning
- Service enumeration
- Vulnerability identification

## Phase 3: Exploitation
- Manual exploitation
- Automated tools

## Phase 4: Post-Exploitation
- Privilege escalation
- Data exfiltration
- Persistence
```

## Custom Commands

```bash
# Quick notes
note() { echo "$(date): $1" >> ~/pentest/notes.txt; }

# Screenshot
screenshot() { import -window root ~/pentest/screens/$(date +%Y%m%d_%H%M%S).png; }

# Quick findings
finding() { echo "## $1\n### Severity: $2\n\n$3" >> ~/pentest/findings.md; }
```
