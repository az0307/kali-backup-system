SECTION 1: QUICK START
════════════════════════════════════════════════════════════════

BOOT FROM USB:
1. Insert USB into target computer
2. Boot from USB (F12, F2, or ESC)
3. Select "Live (amd64)"
4. Username: root, Password: kali

START MAIN MENU:
  sudo /scripts-desktop/MENU

QUICK COMMANDS:
  ai-menu              - AI tools launcher
  opencode            - AI coding assistant
  hexstrike           - Security AI
  network-scan        - Scan network
  wifi-scanner        - Find wireless networks

NETWORK SCANNING:
  nmap -sn 192.168.1.0/24     - Discover hosts
  nmap -sV target              - Version detection
  nmap -sC target             - Default scripts
  nmap -p- target              - All ports
  nmap -O target               - OS detection

WEB TESTING:
  nikto -h target              - Web vulnerability scan
  sqlmap -u target             - SQL injection
  gobuster dir -u target       - Directory busting
  dirb target                 - Directory scanner
  wpscan --url target          - WordPress scan

PASSWORD ATTACKS:
  hydra -L users.txt -P pass.txt target ssh
  john hash.txt                 - John the Ripper
  hashcat -m 0 hash.txt wordlist.txt

SECTION 6: PASSWORD OPERATIONS

WINDOWS PASSWORD RESET:
  fdisk -l                     - Find Windows partition
  mount /dev/sda1 /mnt        - Mount Windows
  cd /mnt/Windows/System32/config
  chntpw -i SAM               - Interactive reset

HASH DUMPING (ON TARGET):
  mimikatz                    - Windows credentials
  secretsdump.py              - SAM database
  pwdump                      - Password hashes

PASSWORD CRACKING:
  hashcat -m 1000 -a 0 hash.txt wordlist.txt  (NTLM)
  hashcat -m 2500 -a 0 hash.txt wordlist.txt  (WPA)

SECTION 8: TROUBLESHOOTING
════════════════════════════════════════════════════════════════

WIFI NOT WORKING:
  1. Check: iwconfig
  2. Enable: ip link set wlan0 up
  3. Monitor: airmon-ng start wlan0

NO INTERNET:
  1. Check: ip addr show
  2. DNS: ping 8.8.8.8
  3. DHCP: dhclient eth0

TOOLS NOT FOUND:
  1. Update: apt update && apt upgrade
  2. Install: apt install <tool-name>
  3. PATH: echo $PATH
